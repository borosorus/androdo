Androdo · Design study 02

One window. Two identities.

Compare the folded A and phone/archive marks in the same proposed layout. All names, dates, counts and backup states are fictional. These are illustrations; app controls inside them do not run operations.

Proposed changes: a stable brand position in the titlebar, separate USB and backup status, a smaller device illustration, readable destination and scope rows, and a persistent progress strip. This study is separate from the working app. Real macOS chrome, toolbar behavior, keyboard access, contrast and responsive layout require implementation checks.
